# 威胁建模工具

浏览器里的数据流图(DFD)威胁建模工具,替代白板拍照:模型即数据,可持续维护、可评审、可导出报告。

## 启动

```bash
npm install
npm run dev      # 开发
npm run build    # 产物在 dist/
```

纯前端,无后端。模型自动保存在浏览器 localStorage,可通过「导出 JSON / 导入 JSON」归档或随代码库提交。

## 功能

- **拖拽画 DFD**:外部实体(矩形)、处理过程(椭圆)、数据存储(开口矩形)、信任边界(虚线框,可拖右下角缩放),数据流(连线模式依次点两个元素)。
- **自动威胁推导**:按 STRIDE×DFD 映射对每个元素/数据流生成威胁;**跨信任边界的数据流**(虚线红色,带"跨边界"标记)自动叠加 4 条边界威胁。
- **威胁处置**:每条威胁可记录缓解措施、负责人,状态分为 待处理 / 待复核 / 已缓解 / 已接受。
- **变更联动**:图改动(改名、移动进出边界、改连线、删元素)后,受影响的旧威胁自动标为**待复核**,已填写的缓解措施和负责人保留;来源被删的威胁标"来源已删除",由人确认后移除。
- **导出报告**:一键导出 Markdown 报告(元素清单、数据流、按 STRIDE 分类的威胁表、待复核清单)。

## 威胁库分类口径(src/threatLibrary.js)

一级分类用 STRIDE 六类,适用对象遵循微软 DFD×STRIDE 经典映射:

| 对象 | S 欺骗 | T 篡改 | R 抵赖 | I 信息泄露 | D 拒绝服务 | E 权限提升 |
| --- | --- | --- | --- | --- | --- | --- |
| 外部实体 | ✓ | | ✓ | | | |
| 处理过程 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 数据存储 | | ✓ | ✓ | ✓ | ✓ | |
| 数据流 | | ✓ | | ✓ | ✓ | |
| 跨边界数据流(叠加) | ✓ | ✓ | | ✓ | | ✓ |

当前内置 19 条威胁条目(元素 15 条 + 跨边界 4 条),每条含标题、描述、默认严重度、建议缓解措施。**口径调整只改 `threatLibrary.js` 这一处**,保证各系统模型之间可比。

## 待复核的判定逻辑(src/engine.js)

每条威胁记录一个"上下文指纹"(元素:名称+类型+所属边界;数据流:名称+两端元素+是否跨边界)。图变更后指纹对不上的威胁 → 待复核;推导中已不存在的威胁 → 待复核 + 来源已删除。复核后在威胁卡片上重新标记状态即可。
